# 实际GUI 0.2.0-dev交互

依据docs/design的0.3线框迁入Rust/eframe，保留现有原生输入/通信/存储路径。

- 五项导航：总览、设备与屏幕、本机鼠标、剪贴板与文件、设置；状态与停止入口常驻，向导/确认窗口也可停止。
- 多机向导实际创建本机身份、发现或手动地址、核对真实证书指纹、登记、保存本机接收偏好、布局与通信。发现不登记、不授权；不复制私钥；配对码、文件选择器、多设备/精细拓扑明确尚未实现。
- “连接设备”只启动通信，忽略旧native/allow偏好；“启用键鼠会话”需本次明确确认，工作进程复查权限。仅通信升级时先停止旧进程，成功收尾后重连；失败/超时不自动继续。
- 通信与输入状态独立。managed子进程通过独立kind=input事件报告软件路由；GUI不把Authenticated当正在控制，不把旧Local/Disabled缓存当最终清理。整个supervisor结束后才发terminal记录，GUI等待stdout完整结束且无读取错误再认定软件收尾。它不证明OS或应用已收到输入。
- 停止是cooperative：session先释放软件账本/恢复source再返回。错误保留RecoveryUnconfirmed。超过3秒不自动杀进程；强制结束需GUI明确确认，Native残留未知时禁止本窗口再开启Native。仅通信的停止慢不会制造输入恢复未知，但会取消queued upgrade。
- 全局本机手势仍关闭并标开发/验收中；规则真实读写、图形/中文方向选择、冲突与只读恢复、离线画布和显式标注导出接通。可以从识别轨迹创建未保存、未启用规则；应用选择器未提供，必要精确标识手动输入，技术字段下沉。新建/危险规则默认不纳入预览。保存不授权捕获或动作。
- 剪贴板/文件各自有页面与明确不可用状态，不显示示例文件/假进度，不读取系统剪贴板，不开放数据权限。托盘/菜单栏尚未提供；关闭窗口请求停止并等收尾，未确认不假报正常后台运行。
- 原设置/身份/无效未来版本不覆盖，显式恢复先备份；只读时不能新增登记、布局、授权或保存，但停止/撤销入口保留。

GUI与CLI本批开发版本统一0.2.0-dev，package标签/Info.plist取workspace版本。网络Input/ALPN仍v5，旧connection IPC schema1不变；新input事件是独立可忽略记录。没有G2、任意脚本/命令、第二输入hook或系统安全设置修改。

验证：全部Rust检查与三平台CI、managed/probe/reconnect/cleanup故障、GUI真实启动/隔离Xvfb样本导出和最终候选产物均须完成。--ui-layout-report仅显式隔离录制测试，一次create_new导出纯widget矩形，不含输入内容，正常GUI不写该文件。本机Rust仍按用户决定不安装；不得把headless render/CI等同于物理输入验收或#10旧根因定位。

## 0.3.0-dev：设备中心工作区（2026-11-06，首批结果）

用户已确认Oink整合方案并要求界面减少工程化表达。本批保留五页中文导航，使用新的
浅/深主题、圆角卡片和状态胶囊。总览与设备页共用真实工作区：本机/已登记设备卡、
相对主屏摆放、键鼠主操作同页，不生成演示设备；未添加时只有明确的添加入口。

主状态独立于原始诊断字符串，按当前child/连接/输入/停止/terminal/恢复未知事实
呈现。认证成功仍只显示“已连接，键鼠尚未开启”，死进程/断线不显示旧远端归属；
未成功退出在主界面提示，恢复未知优先。主按钮仅打开新的明确同意窗口，不因设备
已登记或保存过native偏好而启动输入；只读和恢复期间不能用该入口开启新会话。
停止、失焦、重新添加设备或改变接收选择都会取消尚未提交的勾选；提交时消费本次
确认，不把旧窗口里的同意自动带到另一台设备或下一次尝试。

高级连接、原始状态、证书/网络角色、撤销信任与发现保留在折叠区域；设置的主要权限
入口查询实际输入程序，上次快照不是执行许可。GUI自身权限/原始日志下沉到高级诊断。
“连接卡”仍是PG-CONNECTION-1公开材料交换，须独立核对完整指纹，不是假配对码。

屏幕图形为两台主屏相对方向示意，响应窗口尺寸，不宣称OS显示器尺寸。拖动预览
保留按下偏移，松开后保存相对方向；覆盖本机/拖出画布不修改，失焦/隐藏/尺寸变化/
活动会话/打开向导时取消草稿。停止仍合作清理，恢复未知仍留警告，未增加全局hook。

版本统一0.3.0-dev；输入v5、存储schema和默认关闭策略不改。短码、托盘、G1、数据、
音频尚未接通。0eb687a完整五项/两平台驻留通过，本机实际首屏/浅深主题/取消复查已做；

## 0.3.2-dev：可选菜单栏／托盘（2026-11-06）

设置新增“菜单栏与关闭窗口”（Windows为“托盘与关闭窗口”）。默认两项均关闭，
关闭窗口沿用停止、清理并退出。先选择“显示屏跃的菜单栏／托盘入口”，实际入口
创建成功后，才能单独选择“关闭窗口后继续在后台协同”；不会注册开机启动。

原生菜单只提供“显示主窗口”“停止协同”“退出屏跃”。显示不启动会话；停止取消
排队的键鼠开启并请求现有工作进程收尾；退出等待工作进程和清理结果。恢复未确认
会显示主窗口保留警告。入口不可用时不接受关闭后隐藏；禁用入口会先恢复隐藏窗口。
没有添加输入钩子、全局快捷键或系统权限，也没有从桌面偏好推导键鼠／数据同意。

桌面偏好独立保存，旧输入配置与身份不变。坏文件／未来版本保留只读，不隐式开启
后台。Linux入口明确不可用。此项仍为实验功能：自动生命周期回归与本机原生验收
分开记录，当前macOS已观察入口创建及选项保存，隐藏后菜单唤回／停止／退出未验收，
Windows原生托盘与Explorer重启未验收，不能视为日常后台协同已经完成。浏览器未验证。
