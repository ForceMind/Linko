# ADR-0013 独立认证的数据连接

日期 2026-11-12。状态为首个传输切片。连接库和回环覆盖与产品启用分别记录。

## 传输边界

输入端点沿用 `peerglide/5` 和原有格式。数据端点使用独立地址入口和
`peerglide-data/1`。它以现有设备证书进行双向 TLS，并在开流前按字节
核对已登记证书和协商的 ALPN。数据端点只接受一个双向流，不接收
单向流或数据报。双方在单个四秒预算内交换固定 8 字节的 PGDH
版本与能力记录。非法魔数、版本、保留位或超时关闭该数据连接。
能力交集仅说明能解析的类型，方向权限由本机同意决定。

产品接入时通过明确操作提供独立的数据监听端口及关闭入口。旧端拒绝
该 ALPN 时，已有输入连接照常处理。数据端点不从键鼠许可自动启动，
不根据局域网提示自动授信。现有身份文件仍采用每次启动和重试的核对
规则。数据会话断开后废弃同意、票据和会话随机数，重连从关闭开始。

## 帧、队列与授权

完成协商后才解析 PGD1。发送端和接收端各有一个有界队列，所有正文
长度在分配前检查。首版文本每方向最多 10 次／秒、每次最多 1 MiB，
文件块采用现有 codec 上限。后续接线在网络和磁盘副作用前都须复核
方向、设备、会话、过期及撤权。无授权、错误会话、长度或格式错误
的对象不能写系统剪贴板或磁盘。接收端采用已有配额和非覆盖写入。
退出与撤销必须能取消在途任务，并让界面区分已发送、收到、拒绝、
取消及结果未知。传输 ID 和取消只在对应的认证数据会话内有效。

数据线程与输入线程分离。正式接入须落实跨流量限速、队列字节预算、
单次传输和空闲超时，保留输入优先。回环验证使用独立生成身份，只做
无系统剪贴板、无文件保存的连接协商。下一切片接入文本方向同意和
真实数据帧，随后再接原生剪贴板、文件及进度。

PGD1 异步收发各自拥有有限字节预算，单帧期限五秒。接收只读固定帧头
后核对类型、预算和方向准入，拒绝时不等待正文。调用方可带回本机票据
并在系统副作用前复核。收发分开持有，避免双方写入时无人读取。半帧
错误或取消关闭该数据连接；发送成功只表示流写入完成。真实回环覆盖
已准入文本、预算用尽及只收到帧头时的拒绝。产品权限、系统后端和
输入／数据共用链路的限速仍待接入。

数据连接从核对过的 TLS 对端证书派生摘要，并由系统随机源为本机
生成独立会话随机数。唯一的本机同意所有者按方向授予能力。收发端
只能检查许可并取得本机票据。实际剪贴板或磁盘写入还要由本机所有者
在副作用前复核。每条连接只接受一次明确同意，修改权限需撤销并
重新建立无权限的数据会话。撤销和所有者退出关闭数据连接，使已
读取的票据失效并取消在途读取。真实回环覆盖默认关闭、单向同意
及收到后撤销。

联网文本复用同一数据会话的剪贴板引擎。发送先分类、检查来源、序号和
回声，再在写帧前复核原票据。接收前采样本机剪贴板版本，帧头准入
后仍在本机写入前验证票据、正文与顺序。状态锁在 OS 版本核对及写入前
释放。内存替身的真实 QUIC 回环覆盖版本变化保留本机编辑、方向拒绝和
收到后撤销。Windows/macOS 的系统后端仍待接入。

文本接收回执携带原序号，表示对方已完整读取并准入文本。它使用
接收方向的本机票据，发送方也必须有发送许可并核对原序号。回执不能
代替实际导入结果，也不授予反方向的剪贴板发送许可。重复回执发送
被本机拒绝，序号不一致关闭数据连接。

文本收达后，发送方可以继续等待独立的导入结果，连接许可在此期间保留。
导入结果只有已向系统提交、版本变化、用户拒绝、失败和未知五类，
不传文字内容。只有带原接收票据的本机完成记录才能发送结果，发送方
按原序号与自身许可复核。已提交不表示其他应用已粘贴。中断时保留
结果未知，不能自动重发。

一次性文本任务由专用后台线程运行独立数据连接，用户可中止。后台线程
在确认收达后持有连接并等待本机决定，系统写入由前台所有者执行。原
票据随决定返回后台，结果送达后结束，最长等待受限。发送方等待导入
结果最多 45 秒，接收方的本机决定最多 35 秒，其他帧仍沿用短期限。
停止或超时即关闭数据连接，未导入文本不能在断线后应用。双 worker
回环使用内存剪贴板，产品界面接线后另有原生验收。
