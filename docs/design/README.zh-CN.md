# 屏跃：中文交互线框

设计版本：0.1.0（信息架构与交互约定，2026-11-05）。独立设计，不复制对标源码、图标、文案或布局资产。

本目录交付桌面产品的线框与可点击原型，不代表原生功能已接通。原型设备、权限、状态均为演示；不联网、不读取剪贴板/文件、不启动捕获或操作系统权限。Rust/eframe 工程和既有授权边界保留。应用版本仍是0.1.0-dev，设计版本单独追踪。

## 目标与导航

让用户先选择“本机增强”或“多机协同”，而不是先理解证书、监听器、工作进程。主界面保留五项：

| 一级页面 | 主要任务 | 下钻内容 |
|---|---|---|
| 总览 | 看懂正在运行什么、下一步做什么 | 本机状态、连接设备、待处理、下一步 |
| 设备与屏幕 | 添加、连接、摆放电脑 | 发现/登记向导、布局、单设备权限、诊断 |
| 本机鼠标 | 建立并管理手势 | 启用准备、录制/选动作/测试/保存、应用规则/排除 |
| 剪贴板与文件 | 明确发送和接收什么 | 文本同步方向、手动发送、接收同意、传输进度 |
| 设置 | 外观、系统权限、配置与诊断 | 权限指引、受限状态、备份/恢复、原始诊断 |

“手势实验室”和“规则”合并进本机鼠标任务流。设备与显示器布局放在同一工作区。所有页面常驻连接摘要、暂停本机手势、紧急恢复本机控制；停止入口不依赖当前导航。

## 核心交互

### 1. 第一次连接另一台电脑

选择添加设备 → 发现结果（尚未信任）/手动地址 → 两端身份核验 → 登记可信设备 → 按用途选择权限（默认全关） → 建立通信连接 → 放置屏幕 → 明确开启键鼠并做跨屏引导。

每一步显示完成状态和失败原因，保留已填写数据，可返回修改。发现不是信任；登记不是授权；连接成功不是键鼠已能控制。“本机允许对方”和“对方允许本机”分开表达，后者不可由本机开关代授。配对码/扫码是目标交互，实际未实现时保留证书核验回退；不假造配对码已可用。网络监听/主动连接与端口下沉到高级连接选项。

权限在设备上下文选择：键鼠、发送本机文本、接收文件独立默认关闭。剪贴板需明确方向；文件需单次接收确认。协作断开后保留信任偏好，不保留“正在控制”显示；重新连接回到本机控制，不自行恢复旧租约。指纹变化停止并重新核验，不能点击普通重试越过。

### 2. 无另一台电脑也能配置本机鼠标

进入本机鼠标 → 了解作用域/独立同意 → 检查需要的系统权限 → 录制轨迹 → 选择适用于本机平台的动作 → 本窗口测试（不执行动作） → 保存规则 → 单独选择是否启用。

测试和保存均不能暗示全局捕获已开启。主开关默认关闭；未接通/未验收的平台显示具体原因和“离线测试”入口。危险动作不预启用，需要额外确认。应用规则采用精确应用优先、应用组次之、全局兜底；排除优先。编辑器直接显示轨迹图、动作名、作用范围和生效预览，数字ID和原始路径放到高级详情。冲突阻止保存，说明冲突对象。

录制画布是窗口内体验，不能称作全局手势验收。全屏/远控/权限变化等暂停原因在当前页说明，可继续配置。暂停或紧急恢复立即中止新动作，恢复完成只由后端确认；未确认显示“恢复尚未完成”，不跳成正常。

### 3. 文本与文件协作

文本同步默认关闭，优先手动发送，明确目标与方向；双向须分别授权。暂停不清空系统剪贴板，不承诺自动识别全部敏感信息。

文件：选择目标与文件 → 发起 → 对端待确认 → 接收位置/空间/重名说明 → 接受一次或拒绝 → 传输/暂停/校验 → 完成。取消与重试/续传区分，不把重新点击当原事务自动重放；完成只在校验和提交成功后显示。进度页可见授权、保存位置、已接收量和失败原因，不展示文件内容。实际跨屏拖拽作为独立未来能力，不拿发送区代替。

### 4. 异常、停止和恢复

| 情况 | 用户看到 | 操作 |
|---|---|---|
| 找不到设备 | 空列表＋检查同网/手动地址 | 保留输入，重试发现 |
| 身份变化 | 身份需重新核验，控制已停止 | 核验或移除信任；不普通重连绕过 |
| 权限拒绝/撤销 | 需要系统处理，具体受影响能力 | 系统指引；不自动申请/修改权限 |
| 连接中断 | 已断开/正在重连，本机控制 | 取消重连，保留信任偏好 |
| 紧急恢复 | 正在停止/恢复 | 无二次确认；等待真实完成 |
| 清理未确认 | 恢复尚未完成，停止新输入 | 保留警告与必要恢复步骤，不假报成功 |
| 无效/未来配置 | 设置只读，原文件保留 | 导出诊断、选择有效备份；确认后备份重置 |
| 关闭主窗口 | 明确后台或退出语义 | 托盘尚未实现时不暗示仍在后台；退出等待清理 |

## 对标依据与独立取舍

- MouseInc配置文档把全局、应用规则、触发与动作分开。屏跃采用“轨迹—范围—动作”编辑器，原始ID不占主流程；不照搬脚本/命令接口或删除坏配置的恢复建议。[配置文档](https://github.com/shuax/MouseInc.Settings/blob/main/docs/docs/config.md)
- Aitiy官方手册描述先录制/选动作/保存，按应用排除，并将暂停、退出放在常驻入口；Infinite Mouse包含配对和相对屏幕布局。屏跃借鉴任务连续性，增加明确的连接/控制/授权区分。[官方手册](https://aitiy.com/docs.html)
- Deskflow、ShareMouse作为跨屏布局和状态的辅助参考；屏跃不复制主从标签或资产，也不宣称已实现其剪贴板、文件拖拽、UAC等能力。[Deskflow](https://github.com/deskflow/deskflow)、[ShareMouse](https://www.sharemouse.com/features/)

上述是公开资料中的交互思想，本次没有安装或实测竞品。它们的权限、性能与安全性不由此得到比较结论。更完整的证据边界见仓库RESEARCH_MOUSEINC_AITIY与REFERENCE_RESEARCH。

## 落地与版本记录

| 设计内容 | 当前工程对应 | 落地边界 |
|---|---|---|
| 设备/信任/连接 | main.rs、discovery_panel.rs | 保留证书核验；配对码、多设备尚需实现 |
| 设备与布局工作区 | devices/displays | 当前只一个对端与相对方向，多显示器是目标 |
| 本机鼠标一体编辑 | gesture_lab.rs、gesture_rules.rs | 复用离线识别与规则；原生G1入口仍关闭 |
| 独立协作权限与收件箱 | data/clipboard/transfer模块 | 网络/系统后端/界面未全部接通，不假报可用 |
| 常驻停止/恢复 | 现有GUI worker状态 | 请求停止不等于恢复成功，保留清理错误 |
| 配置与权限诊断 | config_store/main settings | 原文件/身份不覆盖，不自动改OS权限 |

每个可审阅步骤、每个设计版本都commit并push，不强推，不把几个版本只留在本机。当前分支chinese-ui-wireframes，从owned-local-input/e7d0778派生；旧worker增量保存在local-gesture-worker/PR40，不夹入设计差异。
