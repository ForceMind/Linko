| 实际浏览器流程 | 观察结果 |
|---|---|
| 添加电脑→选择发现项→核验 | 未核对时登记按钮禁用；勾选后才进入用途选择 |
| 登记→独立权限→连接 | 三项默认关闭；通信已连接仍为本机控制、未授权 |
| 开始跨屏→本机准备→对端确认 | 本机不能代授对端许可；演示对端同意后仍需明确开始 |
| 跨屏→急停→恢复未确认 | 保持正在恢复；修正前可再次开始，修正后阻止 |
| 恢复失败→收到确认 | 分别显示“恢复尚未完成”和“当前由本机控制” |
| 本机鼠标→应用选择→反馈→保存 | 保存示例规则后全局仍未启用，不显示执行成功 |
| 画布绘制→切换动作 | 修正前轨迹消失；内存存点并重绘后实际观察轨迹保留 |
| 弹窗内急停 | 修正后在弹窗头部直接恢复，无需先关闭弹窗 |
| 文本自动同步→独立方向授权→切换方向 | 未授权进入权限弹窗；出方向需演示对端允许；换方向关闭旧同步 |
| 文件接收→一次接受→暂停/继续→100%→校验保存 | 未接受不传输；100%仍校验中，最后确认才完成 |
| 配置只读→备份恢复 | 明示原文件保留；显式恢复后授权关闭，未触碰磁盘 |
| Windows/macOS动作列表 | Windows显示最大化，macOS不显示此动作 |
| 对端控制本机→本机输入接管 | 独立显示接收控制状态，接管后等待恢复确认 |
| 手动IPv6示例地址→下一步→返回 | 原输入仍保留，无真实网络访问 |

## 发现并修正

浏览器发现恢复未确认仍可重新控制、表单操作清空绘图。静态交互复核另发现继续手势越过远控/恢复暂停、校验时撤销文件权限仍能提交、只读状态绕过配置写入限制、弹窗遮挡鼠标急停入口；均修正并补状态回归。手动暂停与自动暂停分开，保留用户手动选择。原始地址和草稿保留；危险映射需确认，但保存仍不是运行授权。

针对性复核确认修复成立。这不是完整安全审计，也不构成后端功能验收。
