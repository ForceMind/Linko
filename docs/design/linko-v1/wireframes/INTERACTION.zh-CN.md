# Linko / 屏跃：线稿交互说明

设计线稿 · 非运行界面。本批采用 `bfd739c9a06f11965a9720ff67b6a6fd4b12a625` 中最新 `docs/LINKO_UI_DESIGN.zh-CN.md` 的拓扑首页方向，读取时工作基线为 `ca0f6e7a8f6c43f3219ef74f278a42359022086d`。01–04 旧配色仅属历史，本轮不再候选。

## 文件与场景

- `01-screen-layout.svg`：默认“屏幕布局”。两台已登记主屏的设计示例，对端被选中，右侧是该设备的上下文；连接为仅通信，键鼠未开，本机权限未查。
- `02-devices.svg`：设备管理。设计示例为已登记但离线的对端，按需详情抽屉打开；默认进入此页时抽屉可关闭，列表不承担首页职责。
- `03-add-computer.svg`：未登记场景，从拓扑里的明确添加空位进入配对。仅有本机和添加空位，不用虚构对端填满画布。前景停在首次使用、身份尚未准备的分支。

画布均为 1440 × 960，导航宽约 190 px，右侧内容截止到 1408 px，预留 32 px 安全边距。可编辑中文文本从 14 px 起，不含脚本、远程字体或外链。根代理负责 AppKit 全尺寸静态渲染；本批只检查 XML、坐标与文字，不使用 Quick Look 宽幅缩略图作为完整画面证据。

## 视觉与信息架构

采用瓷白 `#F7F8FA`、白色 surface、石墨文字 `#20252D`、品牌蓝 `#4263EB`、hover `#3651CC`、浅蓝 `#E8EEFF`、边界 `#E2E7EF`；辅助文字使用已加深的 `#5F6F85`，避免旧 `#64748B` 在画布上仅约 4.48:1 的问题。品牌蓝表示选择、焦点或主操作，不表示权限就绪。状态以文字和符号共同表达，不依赖绿色点。

导航固定为“设备、屏幕布局、文件传输、剪贴板、快捷键、设置”，默认进入“屏幕布局”。“文件传输”“剪贴板”明确标记尚未接通。快捷键页保留“本机鼠标”入口，通往现有窗口内预览、手势实验与规则编辑；全局手势 / G1 执行仍为开发中，不因调整导航丢失既有能力。

产品展示名为 Linko / 屏跃；仓库、crate、协议等 PeerGlide 内部标识不在本批迁移。没有远程实时桌面、应用窗口桥、音频、手机控制器或域名购买承诺。

## 默认拓扑首页

主体为大画布，右侧为所选设备上下文。点击主屏只改变选择，不授予键鼠、接收控制或数据权限。未登记时只显示真实本机与“添加另一台电脑”空位；已登记时对端节点仅从现有登记读取，离线和撤销分别显示实际事实。

本轮只支持本机与一台对端、各一个主显示器。节点内的操作系统、显示器尺寸、连接状态均来自真实状态；未知时显示“未知 / 尺寸未知”，不按昵称猜系统，不填造分辨率、延迟或传输进度。

- 本轮实际提供 60–100% 的视图缩放；“− / ＋”在此范围内调整，“适配视图”恢复 100%。这些操作只改变示意的观看比例，不改系统分辨率、相对方向或控制归属。
- 拖动对端主屏与四向按钮表达同一个左 / 右 / 上 / 下方向；移动不构成多屏像素拼接。拖动过程只是预览；释放且上下文仍有效时，才由既有受控写入路径提交方向。四向按钮作为键盘可达的等价入口。
- 本轮尚未提供独立自动排列、独立重置视图、平移或多屏几何编辑；线稿工具栏不展示这些操作。
- Native 会话、配对进行中、配置只读或恢复未确认时锁定布局变更和写入。已提供的缩放与适配仍是视图操作，不绕过锁定。
- 拖动失焦、Esc、切换页面或丢失捕获时取消预览，不落盘。配置版本、设备身份、登记、授权或会话状态发生变化后，旧拖动 / 旧确认结果失效，需重新读取后发起。

右侧将“连接”“输入”“接收控制”分开显示。图 01 的唯一主操作为“检查本机键鼠权限”；只有新鲜 Ready 结果满足既有条件时，才换成“开启键鼠协同…”，该按钮仍进入独立确认。

停止协同与恢复本机始终在右上角可见、可达，切页或打开添加弹层也保留。图 01 仍有仅通信会话，停止入口可用；图 02 离线与图 03 尚未开始配对时无运行会话，停止显示禁用。真实运行中以现有会话状态决定是否可停止，不能以未开启键鼠为由禁用正在运行的 Communication / Native 的停止。恢复请求不是恢复成功回执。

## 设备与按需详情

设备页管理现有登记。列表区分本机与对端，详情通过行选择或菜单按需打开。关闭抽屉保留原选择和滚动位置。详情保留身份、登记、仅通信连接 / 断开、撤销和诊断入口，不额外展示假的实时数据。

图 02 展示离线对端：主操作仍按本机权限事实为“检查本机键鼠权限”；“连接电脑 · 仅通信”为独立的通信入口，不暗示 Native 能力或输入授权。通信已建立时该次级动作替换为断开，不同时摆放连接和断开。撤销需沿用既有确认、锁定和恢复约束；不删除本机身份，不用只关闭窗口冒充撤销成功。

对端接收许可由对方单独设置，本机不显示可以代替对方开启的开关。文件传输与剪贴板仍未接通，无已启用假开关。将来接入需各自授权，设备登记或输入接收许可不包含数据授权。

## 添加电脑

“显示配对码”和“输入配对码”二选一，切换后替换流程内容。图 03 为显示分支的首次使用：点击“准备这台电脑”才创建本机配对身份；准备成功后，再由用户明确点击“显示我的配对码”。已有身份时保留并复用，不重新生成或覆盖。

显示分支在实际启动核验后动态显示本次短码；准备前只写“配对码将在此显示”，复制禁用。输入分支显示空输入框，接收另一台提供的八位数字配对码，不写死示例数字，不将占位内容用于认证。

附近发现默认关闭。显式开启只用于发现本次配对；发现结果不等于认证，不自动登记或开启键鼠。双方核验身份并分别确认后才保存登记；双端收据待确认时显示等待，不能声称完成。取消、超时、陈旧结果或上下文变化不得新增信任或授权；若本机已写入待确认记录，必须保留“登记等待对端回执 / 撤销待确认登记”的真实状态，不宣称两端都未保存。

正在运行或恢复未确认时，添加流程沿用既有前置门槛：先停止并确认本机输入恢复，不用打开设计弹层绕过运行会话。配对完成后回到拓扑页，键鼠仍需 Native 独立确认与对端单独允许接收；配对不自动开启内容共享。

## 状态到唯一主操作

沿用 `desktop_state::present` 的事实与优先级；恢复、停止清理和 Native 输入归属先于普通权限提示。以下是展示映射，不新增授权能力。

| 状态 | 当前事实 | 主操作 |
|---|---|---|
| 未登记 | 只有本机与添加空位 | 添加另一台电脑 |
| 已登记离线 | 已记住，未连接 | Native 可用且权限就绪时开启键鼠协同…；未就绪时检查本机键鼠权限；Native 不支持时连接电脑 · 仅通信 |
| 连接中 / 等待对端 | 尚未连接或正在检测 | 等待当前操作完成；不重复启动。现有 Snapshot 允许的 Communication 准备入口仍按实际状态 |
| 仅通信 | 已连接，键鼠未开 | 权限就绪时开启键鼠协同…；否则检查本机键鼠权限 |
| 权限未查 / 过期 | 缺少新鲜观察 | 检查本机键鼠权限；检查中等待 |
| 权限就绪 | 本机观察为 Ready | 开启键鼠协同…，进入独立确认 |
| Native 运行 | 本机 / 控制对端 / 接收对端 | 不增加启动；固定停止与恢复，布局变更锁定 |
| 停止中 | 等待输入清理及终止回执 | 查看恢复指引，禁止重启 |
| 恢复未确认 | 清理结果仍需确认 | 查看恢复指引，禁止新会话与布局写入 |
| 配对中 / 双端收据待确认 | 正在核验或等待回执 | 当前步骤动作 / 等待；不启动协同，布局变更锁定 |
| 只读 | 配置不可写，资料保留 | 不允许新增启动、配对或布局写入；固定停止与恢复保留 |

## 开发事实校对与未定细节

事实校对读取了 `apps/peerglide-gui/src/desktop_state.rs`、`worker_permissions.rs` 及 `pairing_panel.rs` / `pairing_receipt.rs` / `pairing_supervisor.rs` 中直接相关的映射与门槛：

- 实际同包 worker 权限观察新鲜度为 30 秒，从工作完成时 `Observation.finished` 起算；GUI 读取或重开页面不能刷新旧结果。到期回到 `Unchecked`。只读观察不是输入授权，也不证明实际注入成功。
- Native 开启仍须独立确认，对端必须单独允许接收；信任、输入、数据与动作授权互不替代。新的页面选择和布局提交也不取得授权。
- 配对保存与收据使用代次、身份及上下文核验；待确认收据阻止接收、键鼠和自动重连。取消 / 过期 / 旧代次结果不能授信，已保存记录不能被假装不存在。
- 失焦取消、配置 / 授权变化使布局交互过期为本轮拓扑交互约束；本批线稿不声称代码已实现这些约束。

尚需随实现细化：方向提交反馈、键盘焦点顺序、抽屉在窄窗口的呈现，以及添加流程核验 / 完成步骤的精确排版。当前迭代不扩展到自动排列、独立重置、平移、多屏几何或未来工作空间。

本批未运行应用、浏览器、Cargo 或系统权限操作；仅做设计资产 XML、坐标和文本检查。静态设计图不等于 Native、真实 Windows/macOS 双机或权限验收。
