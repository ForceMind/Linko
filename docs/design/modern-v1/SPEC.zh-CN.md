# 现代化视觉与交互规格 v1

状态：设计提案，先于GUI实现。应用仍为0.3.13-dev；本目录不代表实际功能或验收。

## 视觉方向

参考[UU远程官方页面](https://uuyc.163.com/)的蓝白产品视觉。屏跃采用自己的品牌、图标、文案与任务流程，不引入账号/VIP/广告/云电脑/远程终端业务。

| 项目 | 提案值 |
|---|---|
| 主操作 | 蓝 `#3A7BFC`，文字需通过对比度校验；小字号可用更深蓝 `#1F5ED6` |
| 页面/表面 | `#F5F7FB` / `#FFFFFF` |
| 主/次文字 | `#172033` / `#667085` |
| 分隔线 | `#E5EAF2`，不让每个状态都成为大胶囊 |
| 正常/提醒/危险 | `#16A46A` / `#B77918` / `#D64550`，同时带状态文字 |
| 字号 | 标题24–28，设备名16–18，正文14–16，辅助12–13 |
| 间距/圆角 | 8px节奏，内容间距16/24，卡片圆角10–12 |
| 字体/图标 | 保留已许可中文字体；图标采用统一线宽的原创向量符号 |

AI效果图只是视觉目标，精确坐标、组件状态和文本由SVG线稿/本规格确定。渐变限于品牌图标与小面积插画，不大范围铺光效。

## Oink交互参考与取舍

以下风格判断依据固定参考版本[3ca82127](https://github.com/oinkvm/oink/tree/3ca82127e61f9d7106a70574a82cc63566d7a572)源码，不代表本机运行或物理验收。Oink偏柔和、紧凑的原生桌面工具：圆角面板、细边界、浅深主题、可折叠侧栏和强调色。其[外观定义](https://github.com/oinkvm/oink/blob/3ca82127e61f9d7106a70574a82cc63566d7a572/apps/oink/src/settings/appearance.ts)默认粉色，可选蓝、橙、琥珀和紫；“原生桌面工具风格”是设计归类。

| 源码中的组织方式 | 屏跃本次设计采用的行为 |
|---|---|
| [App](https://github.com/oinkvm/oink/blob/3ca82127e61f9d7106a70574a82cc63566d7a572/apps/oink/src/App.tsx)：设备列表、选择状态、屏幕画布联动 | 两台设备卡与独立布局标签共享当前设备上下文；选择只改变视图，不改变授权 |
| [Arrangement](https://github.com/oinkvm/oink/blob/3ca82127e61f9d7106a70574a82cc63566d7a572/apps/oink/src/arrange/Arrangement.tsx)：直接拖动、吸附与选择反馈 | 此版只表达两台主屏的四向关系，拖动和方向按钮一致；停止并清理后才能修改 |
| [DeviceList](https://github.com/oinkvm/oink/blob/3ca82127e61f9d7106a70574a82cc63566d7a572/apps/oink/src/devices/DeviceList.tsx)：设备旁的能力状态、权限提示和上下文操作 | 卡片呈现少量真实状态，主操作给出下一步；详情按需展开 |
| [AddPanel](https://github.com/oinkvm/oink/blob/3ca82127e61f9d7106a70574a82cc63566d7a572/apps/oink/src/pairing/AddPanel.tsx) / [PairDialog](https://github.com/oinkvm/oink/blob/3ca82127e61f9d7106a70574a82cc63566d7a572/apps/oink/src/pairing/PairDialog.tsx)：附近列表、手动IP回退、显示/输入短码和就地错误 | 显式开启发现，短码向导为主要路径，地址/证书回退放帮助中；保留屏跃的独立输入同意与双端确认 |

组合原则：UU的蓝白视觉层次、Oink以设备为中心的操作组织、屏跃的中文任务引导。产品主流程只说用户需要知道的状态和下一步；worker、协议字段、票据与诊断细节放开发说明或按需详情。Oink的多屏、音频和复杂快捷操作没有因此进入本批实现范围。

## 页面结构

- 左侧约190px，仅五个一级入口；设置在底部。
- “设备与屏幕”默认设备卡片视图，本机+一台对端，单一主操作。
- “屏幕布局”是同页第二标签。主页仅保留小预览和调整入口。
- 设备详情按需从右侧抽屉展开，默认不占第三栏。
- 停止/恢复入口固定可见；恢复未确认时优先显示警告，不能被设备卡覆盖。
- 920×700窄窗口中卡片可单列、抽屉改覆盖层；主操作与取消不能移出可操作区域。

## 状态与授权的真实性

1. 连接、输入归属、系统权限、接收选择分别表达；“已连接”不等于正在控制或对方允许接收。
2. 本机权限只采用实际worker结果，沿用任务完成起算30秒期限；过期重新检查，不能用渲染时间刷新。
3. 对方系统信息未从后端提供时使用通用图形/未知说明，不根据昵称猜系统，不伪造分辨率、延迟或在线状态。
4. 效果图中的“Windows工作电脑”和绿色权限为样例。未实现本机全局G1/数据功能标“预览/开发中/尚未接通”。
5. 开启键鼠仍走原有明确同意及最终校验，不从配对、UI选择或保存偏好自动开启；输入许可不包含数据或动作许可。

## 添加电脑

“显示配对码”和“输入配对码”二选一。首次身份准备显式完成；显示码需要用户发起，运行时随机生成、到期失效，图中的示例码不进入程序。

显示后可显式复制到本机剪贴板；该按钮不等于授权跨设备剪贴板同步。附近发现默认关闭，开启仅用于本次配对；地址/证书手动回退放“连接遇到问题？”。双方确认及保存回执完整后才记住设备，不自动启动键鼠。

取消、失焦、切换方式和陈旧结果继续沿用现有代次/取消/事务约束。存储结果未知时保留记录与诊断，不把它渲染成成功或静默回滚。
