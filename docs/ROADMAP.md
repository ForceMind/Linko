# 路线图

公开下载为 0.3.23-dev 诊断预览。下表记录草稿集成候选的进展，真实双机验收仍待完成。
候选证据见[集中验收清单](VALIDATION.md#集中验收清单)，公开版记录见[功能与交付状态](STATUS.zh-CN.md)。

| 里程碑 | 已有基础 | 完成门槛 |
| --- | --- | --- |
| M0 工程与安全 | 工作区、协议 v5、认证、恢复模型、平台 CI | 持续回归与安全检查；历史故障原因不得以近期 CI 成功代替 |
| M1 双机键鼠 | Windows/macOS 原生实现、主屏边缘切换、键盘跟随、恢复与通信探针 | 真实双机四边、修饰键、拖拽、滚轮、DPI、物理接管、断网、退出、睡眠和权限变化验收 |
| M2 设备协作 | 认证短码、双端登记回执、独立接收许可、IPv4／IPv6 发现、固定证书重连、多证书串行监听和 CLI 外沿分段发送 | 真实局域网、多网卡、权限、三机切换和连接生命周期验收。分段编辑与目标副屏选择仍待接入 |
| M3 桌面体验 | 中文工作区、方向档案、主屏重建、副屏选择与确认、权限诊断、托盘／菜单栏和减少动效 | 真实桌面可访问性、多屏、DPI 与热插拔验收。光标定位、拖尾及高级触摸板手势仍待开发 |
| M4 数据协作 | 独立授权的文本、PNG、显式文件传输、续传、历史、本机复制拖放与音频 | 真实双端数据、应用拖放及音频设备验收。跨机原生拖放与虚拟音频设备仍待开发 |
| M5 发布 | 同源开发包、校验与来源、隔离更新暂存与回滚 | 长期资源观察、真实安装更新、签名／公证与稳定版实际验收 |
| G1 本机鼠标 | 窗口内练习、规则预览与 Windows 受控库工作器，全局捕获和动作关闭 | 后续原生平台接入、焦点与权限制约、退出恢复及真实设备验收 |
| G2 跨设备动作 | 设计草稿 | 当前协议无远程动作和脚本接口 |

## 当前顺序

1. 推进草稿候选和剩余软件项。原生捕获健康与 macOS 完整光标冻结先决定 ADR。
2. 使用同一候选集中验收双向键鼠和恢复，按两端诊断定位剩余输入问题，再验收配对、数据、多屏和音频。
3. Linux Xorg 已有显式接收候选，主动发送和 Wayland 仍待开发。
4. 签名、公证、系统服务、合并、部署及发布各按已有授权流程办理。

CI、模拟输入、界面预览与物理验收分别记录。未完成能力在产品中保持关闭或明确标记，不以发布预览宣称稳定可用。
