# 路线图

公开下载为 0.3.17-dev，最新诊断候选为 0.3.22-dev，真实双机验收尚未通过。当前逐项状态见 [功能与交付状态](STATUS.zh-CN.md)。验收证据见 [VALIDATION](VALIDATION.md)。保留既有 M0–M5、G1/G2 标识。

| 里程碑 | 已有基础 | 完成门槛 |
| --- | --- | --- |
| M0 工程与安全 | 工作区、协议 v5、认证、恢复模型、平台 CI | 持续回归与安全检查；历史故障原因不得以近期 CI 成功代替 |
| M1 双机键鼠 | Windows/macOS 原生实现、主屏边缘切换、键盘跟随、恢复与通信探针 | 真实双机四边、修饰键、拖拽、滚轮、DPI、物理接管、断网、退出、睡眠和权限变化验收 |
| M2 设备协作 | 短码认证、双端登记回执、独立接收许可、可选发现与重连基础 | 真实局域网、多网卡、权限与连接生命周期验收；多设备仍待实现 |
| M3 桌面体验 | 中文工作区、两台主屏方向、权限诊断、可选托盘／菜单栏 | 真实桌面验收、可访问性、多显示器精细拓扑 |
| M4 数据协作 | 独立授权模型、离线剪贴板／文件存储、接收管理和有界编解码 | 生产网络、系统剪贴板、跨重启配额、同意／取消／恢复／进度 UI；文件跨屏拖放另行验收 |
| M5 发布 | 可复现开发包、校验与来源、公开预览和中文文档 | 长期资源观察、签名／公证、安装更新、稳定版实际验收 |
| G1 本机鼠标 | 离线识别、画布、规则、上下文与动作基础 | 唯一捕获生命周期内仲裁、真实 Backend、独立同意与权限／焦点／退出恢复；当前全局关闭 |
| G2 跨设备动作 | 设计方向 | G1 和可信会话之后独立授权；无任意远程脚本或命令 |

## 当前顺序

1. 优先完成 Windows + macOS、各单主屏的真实键鼠验收与阻塞修复。
2. 完善连接、配对、停止、权限和日常桌面体验。
3. 分别推进本机 G1 与文本剪贴板，再扩展文件和图片。
4. 后续再扩展多设备、多显示器、Linux 原生后端与其他协作方式。

CI、模拟输入、界面预览与物理验收分别记录。未完成能力在产品中保持关闭或明确标记，不以发布预览宣称稳定可用。
